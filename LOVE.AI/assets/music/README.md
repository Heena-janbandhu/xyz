# 🎵 Background Music Folder

Place your background song here as:

```
assets/music/background.mp3
```

## Song suggestions
- **Perfect** — Ed Sheeran
- **Thinking Out Loud** — Ed Sheeran

## How to get the MP3

Since these are copyrighted songs, you need to source the MP3 file yourself.
Options:
1. **Spotify / Apple Music** — download if you have a premium account, then convert.
2. **YouTube** — find an official audio upload and use a YouTube-to-MP3
   converter (e.g. https://ytmp3.cc or similar). This is for **personal/private use only**.
3. **Purchase** — buy the song on Google Play Music, iTunes, or Amazon Music.

## File format

- Format: **MP3** (`.mp3`)
- Bitrate: 128–192 kbps is fine for web
- Rename the file to exactly: `background.mp3`

## Note

The music player is already wired up in `js/main.js`.
It will silently fail (no error shown to Yash) if the file is missing,
so the site works perfectly fine without music too.
